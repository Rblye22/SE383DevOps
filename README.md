# SE383.58 DevOps

This is a simple web application where users are shown a question and two options to choose from. The user picks which option they would rather do. After they vote, the user then sees the results of the poll, showing how many people voted for each option.Users will be able to ask their own would you rather questions for other voters. 

The app will conist of a front-end that user sees and interacts with, a back end that handles logic and questions, and a database that stores the questions and votes. The Api will handle asking a question from the databse and showing the results and counting votes for each choice on the question asked. The database will be a simple SQL database that stores the Question, Option A, Option B, and the number of votes for each option.
